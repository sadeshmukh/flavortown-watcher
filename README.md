# Flavortown Watcher

_Big Flavor Brother_ is always watching.

Inspired by the Arcade HCB tracker (#arcade-hcb-tracker), this posts messages whenever new transactions happen on the Flavortown HCB.

![alt text](https://cdn.hackclub.com/019ce023-d7c4-771a-b5c3-56bff300c4a8/image.png)

To run it yourself, copy `.env.example` to `.env` and fill in the values. Make the bot by copying in the `manifest.yml`. Run `uv run main.py` to start it.
